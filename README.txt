NO LIMITXX - Conversion PWA

1. Ajoute manifest.json à la racine du projet.
2. Ajoute sw.js à la racine du projet.
3. Copie le code HTML dans ton fichier index.html.
4. Ajoute deux icônes :
   - icon-192.png
   - icon-512.png

Résultat :
- Ton site pourra être installé comme une application.
- Certaines pages fonctionneront hors connexion.
- Chargement plus rapide sur téléphone.
